GitHub MD Review Active

Add inline comments on GitHub's rich diff view for markdown files

How to use:

  1. Open a PR with markdown files
  2. Click "Display the rich diff" button on a .md file
  3. Select text you want to comment on
  4. Type your comment and submit
Features:
  • Works with GitHub's native rich diff
  • Select any text to comment
  • Comments include selection reference
  • ⌘/Ctrl+Enter to submit
